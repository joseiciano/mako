# System Design

## Goals

This document is to go over the initial designs for Mako, technical interview and mock interviewing platform. 

For this initial design we are working on the following:

1. Creation of scheduling and doing system design interviews
2. Creation of AI and p2p system design interviews
3. Feedback and data generated upon completion 
4. Creation of user accounts and payment for credits to do interviews 

What we are not focusing on initially (but will be doing in follow ups):
* Behavioral Interviews
* Coding Interviews 
* Learning Resources
